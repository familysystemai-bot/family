لوحة تحكم غنية بالميزات الفاخرة

تم تصميم منصة KognitixAI خصيصاً لتلبية احتياجات الإدارة ومراقبة حركة الفروع والعملاء بدقة متناهية.

تحليلات مالية فاخرة

رسوم بيانية تفاعلية لحركة المبيعات اليومية، إحصائيات استهلاك الـ LLM وتتبع حركة تفاعلات الشات الذكي عبر الفروع المختلفة.

صندوق وارد واتساب ذكي

لوحة محادثات موحدة تمكن المشرفين من مراقبة إجابات الذكاء الاصطناعي، والتدخل يدوياً، وإيقاف أو تفعيل الـ AI بضغطة زر لكل رقم.

إدارة مركزية للفروع

ربط فروع مجمع العائلة بالكامل، إسناد صلاحيات محددة لمدراء الفروع، وربط وتحديث بيانات المنتجات والأسعار بشكل فوري.

حملات واتساب التسويقية

إنشاء وإدارة الحملات الإعلانية المباشرة، إرسال رسائل جماعية للعملاء المهتمين، وتتبع نسب التسليم والقراءة بدقة.

إدارة شكاوى متقدمة

نظام تذاكر شكاوى متكامل للعملاء، يصدر أكواد استعلام ويسمح للإدارة بحلها وإرسال الردود وتوثيق ملاحظات الحل للعميل.

أمان وموثوقية الهوية

تحقق صارم للوصول (مدراء، فروع، مؤسس)، وإمكانية تعديل الشعار وهوية الشات البصرية العامة والخاصة باللوحة لتعكس الهوية التجارية.

كيف يعمل النظام؟

ثلاث خطوات بسيطة لنقل مجمعك التجاري إلى عالم الأتمتة الكاملة والذكاء الاصطناعي.

01

ربط الإعدادات والتكاملات

يتم ضبط مفاتيح جوجل (خرائط وتحليلات Search Console) وربط حساب Meta Cloud API الخاص بالواتساب في لوحة التحكم بأمان.

02

تغذية السجلات والمنتجات

إدخال الفروع وإعداد حساباتها الرسمية وتغذية سجل المنتجات والأسعار وتحديث الهوية البصرية المناسبة للنشاط التجاري.

03

الأتمتة ومراقبة الأداء

يبدأ وكيل الذكاء الاصطناعي بالرد فوراً، بينما تقوم الإدارة بمراقبة التقارير المالية وحركة الشكاوى وصندوق الوارد وتدخل المشرفين.

تكامل واتساب ثنائي القناة مع الإشراف المباشر

الجمع الفريد بين ردود الذكاء الاصطناعي الفورية وإمكانية التدخل البشري. لا تفقد عميلاً أبداً بسبب إجابة معلقة.

  • مساعد ذكي يجيب فوراً بالأسعار ومواقع الفروع.
  • إمكانية إيقاف الذكاء الاصطناعي (AI Block) لرقم محدد ومتابعة المحادثة يدوياً.
  • صندوق وارد موحد يعرض كود الفرع واسم العميل وتفاصيل المحادثة كاملة.
  • دعم كامل لاستقبال وإرسال الصور والمستندات والوسائط والموقع الجغرافي.
